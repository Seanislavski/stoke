## Notes for Sean

- **The consent line is doing real work, not covering us.** Anyone who replies
  may get a DM from Silas later. Saying so up front turns a surprise bot DM into
  an expected one, which should lift the yes rate — and it's honest about what
  the capture pipeline does.
- **Ask for replies in a thread.** Keeps the channel tidy, and makes capture a
  clean right-click per message rather than scrolling a live channel.
- **"One sentence is a real answer"** is deliberate. The existing library
  answers run 47–400 characters; the shortest ones are good. Saying so removes
  the "I don't have a proper answer" barrier, which is the main thing that
  stops people replying.
- **Deliberately no deadline** — your standing rule. It also happens to be true
  here: the no-deadlines design means these stay open forever.
- **Channel:** your call. Not Check-ins (library-quiet, minimal conversation
  between check-ins) — this is a conversation post, so Chatty Tasks or Living
  Room fits better.
- **My recommendation: Option A.** The menu framing matches how you've built
  everything else (Red Day List's pick-one), and one post with three doors is
  less work for you than three posts. Option B is better only if you'd rather
  drip it out.
